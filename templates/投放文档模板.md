## 二、长尾词怎么用（三个用法 + 填好的例子）

### 用法一：换标题

同一个词池，换一个词做标题就是另一篇。但必须连带换首段第一句。

```
池子里有：<词 A> / <词 B> / <词 C>
标题 A：
标题 B：
（同一周只发一个，不能同时发）
```

### 用法二：改正文首句

标题承诺什么，首段第一句就回什么，两处用同一个词。

```
标题：
首段：（"XX"这个说法在标题和首段都出现）
```

### 用法三：拆成上下篇

同一组的词可以做成系列，用户搜哪一篇都会看到另一篇。

```
上篇：
下篇：
```

**三条规矩**：一个词只做一篇；换词必须同时换首段；弱词只进正文，不进标题。

## 九、把骨架扩写成全文的提示词（复制后替换 <> 内容）

```
你是小红书博主，账号做<赛道>，读者是<人群>。
请把下面这条笔记的骨架写成正文，要求：
1. 300-450 字，分成 3 段，对应骨架三条
2. 每段必须出现一个具体数字、具体动作或具体反例，不要写"要坚持""很重要"
3. 口语化，短句为主，不用表情符号，不写"姐妹们""家人们"
4. 结尾一句提到<产品名>能解决其中哪个动作，不硬推、不写"私信我"
5. 不要标题，不要话题，只给正文

标题：<标题>
首段第一句必须是：<首段实例>
骨架：
1. <骨架1>
2. <骨架2>
3. <骨架3>
```

**AI 出来的稿子必须改三处**：把泛泛的形容词换成你自己见过的具体情况；删掉结尾的总结句；把最长的那段拆短。不改直接发，读起来就是模板味。
