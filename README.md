# 小红书关键词布局 Skill

v0.4.0 · 输入一个核心搜索词，产出一份可直接照着发的投放文档。

给做小红书虚拟资料、靠搜索流量出单的人用。核心判断只有一条：成交来自搜索流量，入口是用户脑子里的那句话，不是标题里堆的词。

一份文档包含九块：使用说明、长尾词池、长尾词三个用法（换标题／改首句／拆上下篇，各配填好的例子）、10-12 条笔记（标题／备用标题／长尾可选／正文骨架／首段实例／话题）、发布顺序、标题句式、反面案例、验收指标、一条写好的完整正文示范 + 扩写提示词。

## 安装

三选一。

**方式一：解压即用（最省事）**

把 `xhs-keyword-layout` 整个文件夹放到技能目录：

| 客户端 | 技能目录 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/` |
| Claude Code | `~/.claude/skills/` |

Windows 下 `~` 是 `C:\Users\你的用户名`。放好后重启客户端或新开会话，技能才会被加载。

**方式二：GitHub 托管**

把整个文件夹推到公开仓库，让对方在对话里说「把这 skill 装进来」并给仓库地址，助手会自己拉取、审计、安装。

**方式三：压缩包转发**

直接发 zip，对方解压到上表目录即可。压缩包内已去掉本机路径。

## 怎么用

触发方式：说「布局关键词」「做SEO选题」「这个词下面写什么笔记」「长尾词」「话题怎么配」，或直接给一个核心词加产品。

最小输入三样：核心词、卖的产品、目标人群。有真实语料效果更好，没有走快速模式。

```
完整模式：核心词 + 产品 + 人群 + 30-50 条真实笔记标题
快速模式：核心词 + 产品（所有词标[推]，不给搜索量数字）
```

采语料不需要爬虫，手动做，三分钟：搜核心词按最热排序，抄前 20 条标题加点赞；再搜 2-3 个衍生词各抄 10 条；存成 txt 一行一条。

跑脚本（只用标准库，Python 3.8+ 免安装依赖）：

```bash
python scripts/analyze_corpus.py 语料.txt --out report.md
```

## 输出

```
xhs/<日期>-<核心词>/<核心词>-投放文档.md    主交付物
xhs/<日期>-<核心词>/01-语料分析.md          仅完整模式
```

投放文档结构见 `templates/投放文档模板.md`，填好的完整范例见 `examples/样例产出-四级投放文档.md`。

**拿到文档之后怎么用**（用户最常卡的两处，技能已写进文档末尾）：

- 长尾词不是拿来堆正文的。三个用法：换标题、改正文首句、拆上下篇。文档里各有填好的例子
- 正文骨架不知道怎么填：文档里有一条已经写好的完整正文（300-450 字）当参照，其余用文档末尾的提示词让 AI 出初稿，再改三处——换掉泛泛形容词、删结尾总结句、把最长那一段拆短

## 已知局限

- 没有语料时，词是推演出来的，只能判断结构能不能拆开，不能当搜索量依据
- 不解决转化。它管「被搜到」，成交还看产品页、定价、信任
- 平台语义匹配随季节和供给变化，同一份词表超过三个月要重跑
- 不内置爬虫，也不建议加。个人号批量抓取的风控成本高于收益
- 不适用于纯推荐流量驱动的品类（颜值、剧情、情绪类），那类吃的是完播和互动
