## 二、长尾词怎么用（三个用法，拿本份词池里的真词举例）

### 用法一：换标题

同一个内容，换池子里的另一个词做标题，就是另一篇笔记。但标题换了，首段第一句必须跟着换，否则点进来发现不对口会立刻退出。

```
池子里有：四级考了三次没过 / 四级老是过不了 / 四级差几分
标题 A：四级考了三次没过｜问题在这
标题 B：四级老是过不了｜可能你一直在补错科
（同一周只发一个，不能两篇同时发——两个标题抢的是同一批人）
```

### 用法二：改正文首句

标题承诺什么，首段第一句就回什么，两处必须出现同一个说法。

```
标题：四级差几分｜差的那几分在哪丢的
首段：差 10 分以内的人，丢分几乎都出在两个地方——听力最后两篇的推断题，和阅读匹配的定位。
（"差几分"在标题和首段都出现，用户一眼确认没点错）
```

### 用法三：拆成上下篇

同一组的词做成系列。用户在搜索页看到其中一篇，点进主页会顺着看另一篇，等于用一篇的量拿两次曝光。

```
上篇：四级听力怎么练｜精听这样做才对（讲方法）
下篇：四级听力总走神｜三个原因（讲问题）
两篇互相在评论区置顶对方，形成闭环
```

**三条规矩**：一个词只做一篇；换词必须同时换首段；弱词（"四级干货""四级分享"这类）只进正文当自然表达，不进标题。

## 八、完整正文示范（第 2 条「四级考了三次没过」，照着这个写法写其余各条）

> 标题：四级考了三次没过｜问题在这
> 话题：#四级 #四级听力 #大学生 #四级真题

考了三次没过的人，我聊过不少，共同点不是懒，是每次都在做同一个动作：把时间平均分成四份，听力、阅读、作文、翻译各占一份，然后每一科都停在"会一点"的水平上。

四级总分 710，四科加权算分，你不需要每科都好。差 10 分以内的人，把第四次的时间按 5:3:1:1 分——听力五成，阅读三成，作文翻译各一成——比平均分配更容易过线。原因是听力 249 分里有 140 分集中在几个固定题型上，规律性强，练三周就能看出变化；作文从 8 分提到 11 分要两个月，从 11 分提到 13 分基本不可能。

具体只有三步。先拿最近三套真题按题型拆开做，算出每科得分率，把最低那科定成主攻；再把七成练习时间给它，其余三科每天 20 分钟维持手感；最后两周整套计时模考，把做题顺序和涂卡时间固定下来，别到考场上才开始试。

资料包里真题是按题型拆好的，听力每套配原文和逐句稿，第一遍做的时候不用自己整理这些。

**这条为什么这样写**

- 第一段不解释、不共情，直接给一个可验证的诊断（平均分配时间），读者会立刻对号入座
- 第二段给了 5:3:1:1 这个具体比例和"为什么听力优先"的成本对比，这是全文唯一有信息增量的地方，也是别人抄不走的部分
- 第三段是动作序列，三步都能当天开始做，不提"坚持""规划"这类没法执行的词
- 结尾一句只说了"不用自己整理"，说清产品省掉哪个动作，没有"私信我""评论区扣 1"

## 九、把骨架扩写成全文的提示词（复制后替换 <> 内容）

```
你是小红书博主，账号做四六级备考资料，读者是考了两三次还没过线的大学生。
请把下面这条笔记的骨架写成正文，要求：
1. 300-450 字，分成 3 段，对应骨架三条
2. 每段必须出现一个具体数字、具体动作或具体反例，不要写"要坚持""很重要"
3. 口语化，短句为主，不用表情符号，不写"姐妹们""家人们"
4. 结尾一句提到四级资料包能解决其中哪个动作，不硬推、不写"私信我"
5. 不要标题，不要话题，只给正文

标题：四级考前一周｜只看这4样
首段第一句必须是：最后一周别再背新词了，这时候背的记不住，还会挤掉已经会的。
骨架：
1. 四样必看：作文模板、听力真题 2 套、高频词、翻译常用句式
2. 每天安排：上午 9 点做整套听力，和考试时间对齐
3. 考场流程预演一遍，包括涂卡时间
```

**AI 出来的稿子必须改三处**：把泛泛的形容词换成你自己见过的具体情况（"很多同学"改成"我表妹去年就是这样"）；删掉结尾那句总结（AI 几乎每篇都会加一句"希望对你有帮助"）；把最长的那段拆短。不改直接发，读起来就是模板味，读者能感觉出来。
